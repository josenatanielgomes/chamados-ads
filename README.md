# API de Chamados
## Estudante
José Nataniel Gomes Pereira

## Objetivo
Criar uma API REST simples utilizando Flask para simular o início de um sistema de chamados.

## Instalação
uv sync --locked
## Execução
uv run flask --app app run --host=0.0.0.0 --port=5000
## Acesso
Abra no navegador:

http://localhost:5000/
